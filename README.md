# AI-CodeGenie 🚀

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

## 📌 Project Description

AI-CodeGenie is a smart code generation system that uses advanced AI models to generate code from natural language input. It helps developers write code faster and more efficiently.

## ✨ Features

* 🔹 Generate code using AI
* 🔹 Supports multiple programming languages
* 🔹 User-friendly interface
* 🔹 Fast and accurate responses

## 🛠️ Tech Stack

* Python
* Flask / Backend Framework
* Hugging Face API
* HTML, CSS, JavaScript

## 🚀 How to Run

1. Clone the repository:

   ```bash
   https://github.com/vyshnaviMoka/AI-CodeGenie.git
   ```
2. Navigate to the project folder:

   ```bash
   cd AI-CodeGenie
   ```
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:

   ```bash
   python app.py
   ```
